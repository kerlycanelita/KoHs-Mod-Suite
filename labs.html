How a lab runs

          
A real client and a real server on one machine, one clock for both, and nothing trusted until the anticheat proves it is listening.

        


        

        

          

            
            
Local only

            
The bench refuses any server that is not on the same machine, and does nothing unless the game was started for the lab.

          

          

            
            
Calibrated

            
Every session sends one deliberately wrong packet. If Grim does not flag it, the session's "no alerts" does not count.

          

          

            
            
Fair play first

            
Nothing a mod ships may create, repeat or send a click early. An idea that trips the anticheat is measured, written up — and dropped.

          

          

            
            
Written up

            
Each lab ends in a public write-up in the mod's repository: the setup, the tables, what failed and why.
