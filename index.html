03 // the creator

Zymery Dria

a.k.a. zymekoh · kohzemyora

KoHs Mod Suite is a one-person studio. Every mod and plugin on this page — the code, the configuration screens, the artwork and every single update — is designed, built and maintained by Zymery Dria.

The goal is simple: tools that make Minecraft PvP feel sharper and look better, built with fair play in mind. Bugs, ideas and feedback are always welcome on Discord.

Zymekoh specializes in advanced-level Minecraft servers — from custom plugins to full networks — and in the bridges that let client mods and server plugins work together.

Specialties

  • Advanced server development
  • Plugin development · Paper & Spigot
  • Mod ↔ plugin bridges
  • Fabric mod development
  • BungeeCord & Velocity networks
  • Server audits
Modrinth profile Discord GitHub Buy me a coffee

  • Fair play first

    No auras, no auto-totems, no hidden automation. Each description says exactly what changes.

  • Client-side mods

    Every Fabric mod runs on your client only — nothing to install on the server.

  • Always up to date

    Builds from Minecraft 1.21 up to the latest 26.x releases, version by version.

  • Open source

    Most projects keep their source code public on GitHub.
